# Rajnesh Kr. Ranjan - Modern Portfolio Website

A stunning, fully responsive portfolio website built with **React**, **Tailwind CSS**, and **Vite**. Features modern design patterns including glassmorphism, neumorphism, dark/light mode, smooth animations, and more.

## ✨ Features

✅ **Responsive Design** - Mobile-first, fully responsive across all devices
✅ **Dark/Light Mode** - Toggle between themes with smooth transitions
✅ **Modern UI Patterns** - Glassmorphism, Neumorphism, Minimalist design
✅ **Smooth Animations** - CSS animations and transitions for delightful interactions
✅ **Performance** - Optimized build with code splitting
✅ **Accessibility** - WCAG compliant with proper semantic HTML
✅ **SEO Optimized** - Meta tags, structured data, and accessibility
✅ **Production Ready** - Clean, maintainable, scalable code
